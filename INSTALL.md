# OPAM Package installation

Install the Csv package:

```console
$ opam update
$ opam upgrade
$ opam install csv
$ opam install qcheck
$ opam install lwt_ssl
$ opam install cohttp_lwt_unix
$ opam install lambdasoup
```

# Running the Program

Use the command

```console
$ dune exec bin/main.exe
```

Then, follow the prompts!
